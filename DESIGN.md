# Miyaar design


## Reference-led workflow integration
Use a navy shared header, light grouped navigation, restrained action cards and
cool neutral canvas. Four stages lead from sources to evidence, priorities and
reports; the assistant remains accessible throughout. Its right-side context
contains the actual selected report and model availability, moving above chat on
phones. Existing source-backed metrics and human approval remain. The parent
inspected supplied image pixels; this implementation uses that audit, existing
fonts and artwork. No fabricated reference statistics or Stitch generation.
