# Miyaar design


## Reference-led workflow integration
Use a navy shared header, light grouped navigation, restrained action cards and
cool neutral canvas. Four stages lead from sources to evidence, priorities and
reports; the assistant remains accessible throughout. Its right-side context
contains the actual selected report and model availability, moving above chat on
phones. Existing source-backed metrics and human approval remain. The parent
inspected supplied image pixels; this implementation uses that audit, existing
fonts and artwork. No fabricated reference statistics or Stitch generation.

## Route composition correction

Use a stable 32px content inset on desktop, 12px on phones. Align content to
its navigation edge instead of centering narrow panels in a large empty canvas.
Wide views use the available width up to 1400px; short forms stay readable.
Dataset source cards form the primary column; usage and live-source controls
form a secondary column. Keep one upload CTA, quiet mapping/analysis actions,
compact units, semantic focus states and no decorative control glows. The same
shell, title scale and card tokens apply across routes in English and Arabic.
Do not add fictional operational metrics or illustrations to fill empty space.

## Stitch reference and report inspector

The [dated Stitch brief](docs/design/STITCH_REFERENCE_2026-10-25.md) preserves the
reference study and evidence safeguards. Its older proposed palette is historical;
the approved current tokens remain authoritative. Adopt the source-backed mobile
category labels and responsive report inspector without replacing the current shell.
