### 13.1 What the arithmetic supports

The presentation's annual licence example is:

~~~text
5 human agents × US$165 per agent per month × 12 months = US$9,900 per year
US$9,900 × the deck's historical exchange rate 5.1991 = R$51,471.09
R$51,471.09 / R$161 average order value = approximately 319.7 orders
~~~

These arithmetic operations were checked. The underlying prices, exchange rate, average order value and purchasing assumptions were not newly verified. [S05, slide 7]

### 13.2 Required correction to the interpretation

The approximately 320-order figure is a **gross order-value equivalent of the licence expense**. It does not establish how many incremental orders are needed to cover all costs.

Reasons:

- Gross sales value is not contribution margin.
- The dataset does not establish which orders an intervention would retain incrementally.
- Partner fees, implementation, integration, support, training and shipping upgrades add cost.
- An order that would have occurred anyway is not an incremental benefit.
- Reduced poor reviews do not automatically translate into a known revenue or profit gain.

A defensible break-even calculation needs total incremental cost and expected incremental contribution attributable to the intervention:

~~~text
Break-even incremental retained orders
  = total incremental programme cost
    / expected net contribution per incremental retained order
~~~

If the main benefit is avoided support work or compensation rather than retained orders, build that benefit model separately, with evidence and without double counting.

### 13.3 Transferable management principle

Build the value case around a decision, a measured baseline, a feasible intervention and a credible counterfactual. Use conservative, base and optimistic assumptions when material. Keep actual outcomes, targets, forecasts and scenarios visibly separate.

For RMD, a failure-risk score has value only when it changes a feasible action and improves an agreed outcome after considering inspection, disruption, false alarms and missed failures. This is a proposed evaluation principle, not a claim about a current RMD model.
