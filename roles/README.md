## Collaboration
1. Send repository owner your GitHub username for a collaborator invitation.
2. Create a feature branch from `main`; do not commit directly to `main`.
3. Place safe source code, anonymized synthetic test fixtures, methods and evidence in your own folder. Do not duplicate unrelated modules.
4. Open a pull request targeting `main`, request a peer review and link findings to calculations. Never claim tests passed unless executed.
5. Use `AGENTS.md` and `CLAUDE.md` for mandatory repository standards. Existing role specifications and application code remain authoritative.

## Deliverable responsibility
The academic final submission is one integrated dashboard (.pbix), presentation (.pptx) and report (.pdf). File ownership and reviews must follow the team's private coordination plan; this public repository is for non-sensitive contributions only.
