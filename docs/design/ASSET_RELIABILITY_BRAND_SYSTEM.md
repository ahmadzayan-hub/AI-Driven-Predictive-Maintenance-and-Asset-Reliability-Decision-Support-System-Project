# Asset Reliability AI | Brand and product experience

Status: design implementation, not a production-readiness certificate. 18 October 2026.

## Design decision
Keep existing React/FastAPI/Hermes architecture and UI tokens. New artwork is an **original vector adaptation of the previously generated AI logo and graphic direction**, for integration in the web shell, maintenance preview, favicon and README. Generated dashboard photographs are concept mock-ups containing imaginary numbers; they must not be presented as evidence or as a live monitoring screen.

## Product principles
1. Start with the user's decision: dataset quality, risk, evidence and next action.
2. Distinguish measured, derived, predicted, illustrative and unavailable results.
3. Prefer short, human language: "Needs engineering review" over "AI-powered synergistic intelligence".
4. Show provenance and assumptions next to every material recommendation.
5. Never bury AI model limitations below visually attractive KPI cards.
6. Honor WCAG AA, 44px touch targets, full keyboard access and Arabic RTL.
7. Typography and color must communicate hierarchy, not spectacle; reserve gold for intentional accents, not criticality.

## Identity
- Name: **Asset Reliability AI**
- Signature: railway path + evidence nodes + human-approved shield.
- Core tones: deep navy, restrained teal, pale gold. The existing semantic state palette remains authoritative for warnings, errors and success.
- Artwork: `frontend/public/artwork/asset-reliability-mark.svg`, `asset-reliability-hero.svg`, `asset-intelligence-icon.svg`.
- RTA-inspired layouts may be offered as a future authorized organization theme, but this product must not use RTA trademarks, official logos or suggest organizational endorsement.

## Visual validation
- Marketing illustrations contain no operational results, customer identities or plausible false KPIs.
- Real dashboards continue to use actual source-backed backend figures only.
- The `?design=maintenance` environment stays a clearly marked fictional prototype; publishing and approvals remain server-side.
- SVG artwork has accessible titles for standalone use; in the UI, decorative images use empty alt text because the adjacent label supplies the meaning.
- Validate with existing frontend typecheck, unit tests, Playwright, axe, contrast checks, keyboard and bidirectional-layout tests.

## Remaining design work
Document Studio PDF/DOCX/PPTX rendering, actual signed-in organization profiles, asset health explorer driven by current datasets, reviewed brand governance, and optimized photographic image assets remain separately scoped and unverified.
