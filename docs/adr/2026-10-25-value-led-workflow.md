# Value-led workspace navigation

The owner requested a logical, less redundant Miyaar workspace. Preserve the existing
React pages, backend, stored evidence, direct links and approval boundaries.

The primary sequence is Data sources → Analysis & evidence → Priorities & actions →
Reports. Stage numbers identify navigation positions, not completed work or approved
models. Every primary destination remains visible. Secondary destinations appear
within the active stage; deep links open the matching stage. The phone bar follows
the same sequence. Ask Miyaar remains a separate destination across the workspace.

| Existing capability | Treatment and user task |
| --- | --- |
| Datasets | Keep as the first stage: choose and prepare a source. |
| Runs, assets, evidence workspace | Group under analysis; retain each route and all validation details. |
| Overview, approvals, operations | Group under priorities and actions; retain human review and tracking. |
| Dashboard and its report exports | Keep as reports; preserve charts, filters, output controls and provenance. |
| Assistant | Keep separate; expose report selection when there is no bound source. Never select an unrelated report implicitly. |
| Memory, activity, preferences | Relocate under secondary workspace tools; preserve every capability. |
| Assistant personal-statistics rail | Remove this duplicate presentation only. Memory, preferences and activity pages retain the information. |
| Overview's repeated report headlines | Move behind a native disclosure. The decision brief, checks, limitations and approval queue remain. |
| Session actions and optional motion outputs | Retain in their existing secondary locations. No data or code capability is deleted. |

The shell uses existing Dubai fonts and semantic tokens, logical properties,
44-pixel controls, native disclosures and existing reduced-motion behavior. No
dependency or model change is required. Scope is a reversible information-architecture
increment, not a claim that the six inaccessible reference images were implemented.

This navigation decision preceded the parent's later successful reference-image
inspection. The visual follow-up is recorded in the reference-workspace decision.
Local Library image transfer remained unavailable; no Stitch generation is claimed.

Verification: bilingual stage/callback/deep-link/demo tests, chat and overview
regressions, TypeScript, unchanged production budgets and synthetic rendered desktop/
phone accessibility checks. Exact executed results belong in the release evidence.
No remote push or merge is part of this local increment.
