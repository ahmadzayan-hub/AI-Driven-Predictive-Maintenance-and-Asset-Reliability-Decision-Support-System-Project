# Readable Jarvis evidence and compact page hierarchy

Date: 2026-11-02

The owner requested further local design improvements while production release
gates remain separate. This branch starts from tested main `54562e5`; the existing
served checkout and datastore are preserved. Uploaded reference images are not
readable locally through the currently supported transfer path, so no pixel match
is claimed. The actual synthetic Miyaar console screenshot was inspected instead.

Show calculated values with their units, measurement coverage and missing-data
reasons before long answer/reference text. Keep that original text unchanged in
a keyboard-operable native disclosure; unsupported answers stay directly visible.
Sources, calculation tables, speech text and explicit local review remain available.
No metric, confidence, saving or live model status is invented. Remove the nested
fixed-height evidence scroller so expanded evidence follows normal page scrolling.

Use existing palette tokens, restrained decorative radial light and unchanged
event-driven voice states. Common page headings use a smaller responsive scale
and spacing to give data and actions more room; Arabic joins and responsive
wrapping remain native. No new asset, library or provider is introduced.

Actual phone screenshot inspection found the generic light ghost-button hover
overriding the navy console background while retaining pale text. Scope its hover
background to the existing navy border token; the dashboard accessibility journey
now checks the hovered stop control in both languages.

Component regressions cover both languages and visibility of missing-data reasons.
Browser checks retain query, follow-up, cancellation, scope, consent and review
coverage, and now open full references using the keyboard. Screenshots and exact
executed outcomes are recorded separately from production or microphone acceptance.
