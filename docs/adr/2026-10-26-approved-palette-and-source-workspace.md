# Approved palette and source workspace

Status: isolated implementation; local activation and external publication are separate gates.

The owner requested a visible, consistent redesign across existing pages. Retain
the current routes, source-bound assistant, report generator, ownership checks,
and semantic evidence states. The approved light palette is navy #10243A,
canvas #F3F6FA, white cards, primary #2563EB, restrained cyan #0891B2, and text
#1E293B. Cyan is an icon accent, not normal-size text on white. Navigation focus
and labels keep their accessible lighter contrast token. Explicit dark/system
preferences and Arabic shaping remain supported.

Shared headings, spacing, card shape, navigation and action hierarchy apply to
all existing routes. Dataset sources become a responsive card grid with source
identity and metadata above a separate action footer. Storage allowances remain
exact server values in a compact line, not competing executive KPI cards. File
requirements and live connectors remain reachable in the contextual column.
Overview next actions and assistant composition use the same visual hierarchy.
No fabricated charts, model states, figures or new analytical capabilities.

Use existing synthetic component and browser fixtures. Check every route in
English/Arabic at desktop/phone sizes, retained source actions, focus/contrast,
and root overflow. Keep the existing byte budgets. Local visual inspection is
permitted; no live screenshot upload or external data transfer is authorized.
No model inference, security change, Vercel deployment or data mutation is part
of this design increment. Executed evidence is recorded separately from claims
about deployment or visual acceptance.

Browser regression follow-up: category chips retain their group tint but use
the main text token so small labels remain readable. Short desktop dashboards
compact header/chart spacing to keep the first evidence comparison visible;
figures, caveats, labels and minimum touch targets remain unchanged. Preserve
the existing contrast and whole-chart viewport assertions.
