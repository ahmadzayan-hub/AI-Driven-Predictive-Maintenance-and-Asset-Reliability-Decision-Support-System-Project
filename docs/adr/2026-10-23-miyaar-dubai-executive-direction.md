Asset maintenance is the scope, not only preventive maintenance. Historical academic titles, repository identity, domain and source URLs remain unchanged. ## Existing capability map, not new placeholder features

- Today's priorities: Home uses server-backed analysis evidence and exact-run next actions. Unknown data and failed loading remain distinct from zero.

- Decision review: existing Analyses, executive evidence and Review routes preserve assumptions and human approval. No new what-if simulation is claimed.
- Assistance: existing authorized assistant and report-specific RMD discussion remain as implemented. Generic latest-report chat is not substituted for an exact selected report.
- Follow-up: existing Operations work/outcome records remain accessible through More; no invented action owners, completion or measured benefit.

The four primary phone destinations and More are preserved rather than adding decorative tiles for unimplemented capabilities. Per-metric source-bound clarification remains a separate backend contract, not a fake save or assignment grant.
