# MBA analytics reference

The MBA analytics reference is a reviewed collection of original method
summaries, source citations, schema examples and explicit review limits.

[[Knowledge retrieval]] loads it through the existing Markdown collection
mechanism. It supports [[Model validation]] and [[Maintenance decision support]]
without claiming that an analytical agent has invoked it. [[Evidence and claims]]
still require calculations and actual run evidence; [[Soul]] keeps source data
and consequential approvals separate from reference prose.

The public collection excludes original books/slides, raw extraction, personal
details, private paths, dataset records and private reports. Its coverage is
partial and model-context forwarding remains disabled. The comparison guidance
keeps independent calculations, model reasoning, independent review and human
approval distinct. A report, presentation and dashboard share accepted evidence;
an optional video does not replace required course formats.
